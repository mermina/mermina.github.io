## What's here

- `index.html` — the site. Bilingual (English / Íslenska), no framework, no build step.
  Language strings live in one `I18N` object near the bottom of the file.
- `index-standalone.html` — the same page with every image, the favicon and the CV
  inlined as data URIs, so it works as a single portable file.
- Images, favicon and CV.
